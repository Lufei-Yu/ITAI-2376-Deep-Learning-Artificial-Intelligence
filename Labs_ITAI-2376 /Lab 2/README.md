# Lab 2 – Neural Network Basics

## Problem Statement
This lab explores the fundamentals of neural networks by building and training a simple feedforward model. The goal is to understand how perceptrons, activation functions, and basic training loops work.

## Approach
- Implemented a fully connected neural network from scratch or using a deep learning framework.
- Used activation functions such as ReLU and Sigmoid.
- Trained the model on a small dataset (e.g., MNIST or similar).
- Experimented with hyperparameters: learning rate, batch size, and number of epochs.

## Results
- Observed improvements when tuning the learning rate and increasing training epochs.
- Training and validation curves showed expected learning behavior.

## Key Findings
- Activation functions significantly impact model performance.
- Proper learning rate selection is crucial for stable training.
- Even simple networks can achieve strong performance on structured datasets.
