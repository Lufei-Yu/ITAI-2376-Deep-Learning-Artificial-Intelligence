# ITAI-2376 – Deep Learning & Artificial Intelligence Labs

This directory contains the lab assignments for the course **ITAI-2376: Deep Learning and Artificial Intelligence**.  
Each lab focuses on a core concept in modern AI and is designed to be hands-on, code-driven, and experiment-oriented.



## Labs overview

- **Lab 2 – Neural Network Basics**
  - **Focus:** Perceptrons, feedforward networks, activation functions.
  - **Typical tasks:**  
    - Implement a simple fully connected neural network.  
    - Train on a small dataset (e.g., MNIST or similar).  
    - Explore effects of learning rate, batch size, and number of epochs.

- **Lab 3 – Training, Regularization, and Optimization**
  - **Focus:** Loss functions, gradient descent variants, overfitting control.
  - **Typical tasks:**  
    - Compare optimizers (SGD, Adam, etc.).  
    - Use regularization (L2, dropout, early stopping).  
    - Plot training vs. validation curves and interpret results.

- **Lab 5 – Convolutional Neural Networks (CNNs)**
  - **Focus:** Image classification with convolutional architectures.
  - **Typical tasks:**  
    - Build a CNN from scratch or using a deep learning framework.  
    - Experiment with kernel sizes, pooling, and depth.  
    - Evaluate accuracy and confusion matrices on an image dataset.

- **Lab 8 – Recurrent / Sequence Models**
  - **Focus:** Sequential data (text, time series) and recurrent architectures.
  - **Typical tasks:**  
    - Implement RNN/LSTM/GRU-based models.  
    - Work with sequence datasets (e.g., text classification or forecasting).  
    - Compare sequence length, hidden size, and performance.

- **Lab 9 – Advanced / Capstone Lab**
  - **Focus:** Integrating multiple deep learning concepts.
  - **Typical tasks:**  
    - Design a small end-to-end project (vision, NLP, or hybrid).  
    - Perform data preprocessing, model design, training, and evaluation.  
    - Write a short report summarizing approach, results, and limitations.
